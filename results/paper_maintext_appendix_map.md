# Main Text vs Appendix Map

## Main Text

- lifecycle framework and motivation
- Adult baseline lifecycle validation
- cross-domain benchmark summary across Adult, Bank, Covertype, and Diabetes
- Adult full privacy-fairness-fidelity triangle
- short supporting subsection for Bank and Diabetes after implementation

## Appendix Or Supplement

- detailed Bank triangle tables and extra figures
- detailed Diabetes triangle tables and extra figures
- Covertype privacy-utility-only outputs
- extended post-hoc debiasing tables
- additional ablations, runtime notes, and implementation detail

## Scope Guardrail

The paper should not treat every dataset as equally central. The intended narrative hierarchy is:

- lifecycle framework = core contribution
- Adult triangle = flagship stress test
- Bank and Diabetes = supporting replication evidence
- Covertype = boundary case where fairness is not defined
